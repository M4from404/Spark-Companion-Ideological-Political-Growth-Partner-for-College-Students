星火同行 1.2.5（甜声、开口速度与模型可选版） — Windows 便携版

启动
1. 将压缩包完整解压到一个文件夹，再双击“星火同行.exe”。
2. exe 和 _internal 文件夹必须放在一起；不要在压缩包内运行，也不要只复制 exe。
3. 重复双击会打开已有应用。关闭全部星火同行窗口约 5 秒后，本地服务退出。
4. 直接收藏 127.0.0.1 页面不能启动软件；每次使用先打开 exe。
5. 推荐 Windows 10/11 64 位，并已安装 Microsoft Edge。无需安装 Python。

★ 想用 Qwen3.8-27B？双击上一级目录的「切换对话模型.bat」
- 出厂默认是 Qwen3.5-4B：随包自带、约 3.3GB 内存、第一条回复约 1 秒出声，离线可用。
- 想换成 Qwen3.8-27B，双击「切换对话模型.bat」选 [2] 或 [3]，脚本会自动下载并切换，
  切完立即生效、不用重启，想换回来随时再运行一次选 [1]。
- 实测对比（同一台 24 核 / 31GB 内存的机器，纯 CPU 推理）：
    · Qwen3.5-4B   内存约 3.3GB    第一个字约 0.2 秒    一条回复约 5 秒
    · Qwen3.8-27B  内存约 15.7GB   第一个字约 28 秒     一条回复约 40 秒
  27B 的回答更细致，但等待明显更久；内存低于 24GB 的机器建议别选它。
- 两种 27B 档位：
    · [2] Q4_K_M：16.5GB，约 15.7GB 内存，画质（质量）最好
    · [3] IQ3_S ：11.2GB，约 11GB 内存，体积小 5GB，内存紧的机器优先选这个

功能
- 角色立绘、三段动作动画、七段鼓励语音和三关知识问答已随包提供。
- 角色互动、知识闯关可离线使用；动画无法播放时自动显示包内立绘。
- 每关五题，答对四题解锁下一关；答题解析提供资料出处链接。
- 闯关进度按当前 Windows 用户保存。聊天记录在当前窗口会话内保留，进入小游戏再返回可继续聊天。
- 向上查看聊天记录时，新回复不会强行滚到底部；点击“回到最新消息”继续跟随新回复。
- 对话失败后可以点击“重试”，自动重新发送原问题。
- 窗口最小化或切到后台时，暂停角色动画和装饰效果；语音可继续播放。

AI 对话
- 默认接入本地开源模型 Qwen3.5-4B（Apache 2.0 许可，可商用），模型权重与推理程序都随包放在
  runtime 目录里，无需任何 API Key，也不消耗任何付费额度。
- 用「切换对话模型.bat」可一键升级到 Qwen3.8-27B，下载与切换全自动，改完即时生效。
  切换脚本会同时更新 model_config.json 和 runtime\warmup.json 里的模型名，两者必须一致，
  否则开机预热会失败（手动改配置时请一并改这两处）。
- 使用前先双击上一级目录的「启动本地模型.bat」，等窗口提示就绪后再打开本软件。
- 「启动本地模型.bat」会把推理程序交给 runtime\ollama\serve-supervised.bat 托管：
  推理服务意外退出时会在 5 秒后自动拉起，持续运行不会掉线；每次启动的输出都会写进
  runtime\ollama-data\server.log，排查问题直接看这个文件。
- 想关掉推理服务：双击上一级目录的「停止本地模型.bat」。停止后托管进程会一起退出，
  不会再自动拉起。
- 也可以先双击「设置开机自启.bat」，之后开机会自动在后台启动模型服务，不用每次手动开；
  反悔就双击「取消开机自启.bat」。
- 全部文件都在本目录所在盘，不占用 C 盘空间：
  · 模型权重：runtime\models
  · 模型预设：runtime\model-presets（切换脚本用的配置文件模板）
  · 推理程序：runtime\ollama
  · 推理服务日志：runtime\ollama-data\server.log
  · 启动器日志：runtime\logs
  · 应用数据（含浏览器缓存、语音缓存）：runtime\appdata
- 服务地址与模型名在 星火同行\model_config.json 里配置，改完保存即时生效，无需重启程序。
  只写主机端口也行，程序会自动补全 /v1/chat/completions。
- 想换更聪明的模型（需要 NVIDIA 显卡）：把 provider 改成 local，
  再在服务器上执行 vllm serve Qwen/Qwen3.8-27B-FP8 --served-model-name Qwen3.8-27B --port 8000。
- 本地模型服务没启动时，程序会自动回退到免费公共接口兜底，界面不会白屏；
  回退原因记录在 model_provider.log，便于排查。
- 问答内容、角色设定和当前对话上下文只在你自己这台电脑上处理，不经过任何第三方。
- 若把 provider 改成 ark，则改用火山方舟的豆包 Seed 模型，需要在方舟控制台开通模型并填写 api_key。
- 断网且没有本地模型时，仍可使用角色动画、包内鼓励语音和思政小游戏。

语音与网络（本次重点修复）
- 直接使用 Microsoft Edge 内置的微软神经语音「晓伊」朗读，和在线 TTS 是同一批 Azure 声线，
  但由浏览器自己鉴权，不会再被网络策略拦掉，也不需要任何 API Key。
- 出厂音色顺序：晓伊（少女甜声）＞ 晓晓（甜美女声）＞ 雅雅/慧慧（系统本地女声，断网兜底）。
  在音色下拉框里可以随时手动改，改完会记住。
- 开场会静默“热”一次语音通道，之后每条回复都是文字先出、朗读紧随，实测文字与开口只差半秒左右。
  修复前是“文字早就打出来了、朗读要等十几秒才响”，现已消除。
- 朗读音调与语速：在线神经音色轻微抬调（1.14 倍）换取更甜的音色；“甜美童声”按钮再抬到 1.32 倍。
- 若连不上云端神经语音（比如断网），会自动静默降级到系统本地女声，不会整段朗读消失。
- 默认开启自动朗读，点击发送、按回车或使用快捷问题后，每条 AI 回复都会直接读出来，无需点击人物。
- “自动朗读开 / 关”按钮可随时开关声音；发送新消息会停止上一条朗读，避免声音重叠。
- “停止朗读”只停止当前这条回复，不会关闭下一条回复的自动朗读。
- 自动朗读开关、角色音色选择会保存在本机，下次打开自动恢复。
- 麦克风按钮点击一次开始，再点一次停止；需要允许麦克风权限。
- 导航及题目资料链接需要联网。语音仅朗读清理后的正文，不朗读 emoji 和标点符号。

数据与排障
- 学习进度、语音缓存及日志：runtime\appdata（与启动器同级，已从 C 盘迁移过来）
- 启动诊断：上述目录中的 launcher.log
- 页面和语音共用本地服务，端口占用时自动避让。
- 应用使用独立浏览器配置，避免加载日常浏览器的扩展欢迎页。
- 角色动作视频已关闭浏览器原生播放控件（画中画、增强等），角色与背景之间去掉了描边阴影，
  头发等暗部也按新阈值重新抠像，整体和场景融成一体。
